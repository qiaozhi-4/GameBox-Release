# GameBox Core v1.0.0

## 更新内容

- 发布 `core` 独立 Native 制品，`soId` 为 `core`。
- 使用 Release stripped 输出，目标 ABI 为 `arm64-v8a`。
- 完成 ELF 架构、文件大小和 SHA-256 一致性检查。
- 完成本版本与 Release APK 内置 `libxmg_core.so` 的摘要一致性验证。

## 兼容性

- 打包模式：`separate-core`。
- 不依赖其他外部 core：`requiresCore=false`。
- 最低兼容 App `versionCode`：`37`。
- 当前支持 ABI：`arm64-v8a`。

# GameBox v1.2.28

## 更新内容

- 完成 `1.2.28`（`versionCode=37`）统一 Release 构建与发布清单生成。
- 完成 APK 签名、ABI、文件大小和 SHA-256 一致性检查。
- 发布 APK 资产 `GameBox-arm64-v8a.apk`。

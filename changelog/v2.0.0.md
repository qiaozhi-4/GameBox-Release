## 2026-10-07 | v2.0.0 Native 导入与公告改进

- 新增：支持从本地选择并导入游戏 Native SO，导入和启动前会检查 ELF 格式、设备 ABI 与文件完整性。
- 新增：游戏详情页显示 SO 的本地校验状态和远端版本状态，并展示下载进度与校验结果。
- 优化：公告、更新和 Native 版本信息独立加载与失败恢复。
- 修复：修复 Android 11 上打开日志页可能崩溃的问题，并改进 Debug 安装后的启动等待和重试。
- 改动：更新我的勇者 Native：千域地牢扫荡按当前副本事件提交奖励，补充怪物击杀与结算；自动杀怪支持施法时触发。
- 兼容性：最低 Android SDK 为 28。
- 兼容性：当前支持 ABI 为 `arm64-v8a`。
- 兼容性：App `versionCode` 为 `38`。
- 兼容性：所有 Native 组件统一使用 `self-contained-game` 加载模式；core 不配置推荐游戏包名。

# GameBox v2.0.0

## 更新内容

- 支持从本地选择并导入游戏 Native SO，导入和启动前会检查 ELF 格式、设备 ABI 与文件完整性。
- 游戏详情页显示 SO 的本地校验状态和远端版本状态，并展示下载进度与校验结果。
- 优化公告、更新和 Native 版本信息的独立加载与失败恢复。
- 修复 Android 11 上打开日志页可能崩溃的问题，并改进 Debug 安装后的启动等待和重试。
- 更新我的勇者 Native：千域地牢扫荡按当前副本事件提交奖励，补充怪物击杀与结算；自动杀怪支持施法时触发。

## 兼容性

- 最低 Android SDK：28。
- 当前支持 ABI：`arm64-v8a`。
- App `versionCode`：`38`。
- 所有 Native 组件统一使用 `self-contained-game` 加载模式；core 不配置推荐游戏包名。
